# Feed Forward Neural Network (FNN)

## About this Repository

This repository contains my implementations and practical projects on **Feed Forward Neural Networks (FNNs)** using **TensorFlow** and **Keras**.

The objective of this repository is to understand the complete workflow of building and training feed forward neural networks, including data preprocessing, neural network architecture design, model training, evaluation, regularization techniques, and applying FNNs to real-world classification and regression problems.

## Projects

### Customer Churn Prediction

A Feed Forward Neural Network built using TensorFlow and Keras to predict whether a customer is likely to churn based on customer information.

Project workflow includes:

- Data Preprocessing
- One-Hot Encoding
- Feature Scaling
- Train / Validation / Test Split
- tf.data Pipeline
- Feed Forward Neural Network
- EarlyStopping
- ModelCheckpoint
- Model Evaluation
- Model Saving & Loading
